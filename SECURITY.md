# Security

Report PSWasm vulnerabilities through [private vulnerability reporting](https://github.com/Ayanmullick/PSWasm/security/advisories).
Include the affected version or commit, reproduction steps, and impact.
Please keep vulnerability details out of public issues.

For vulnerabilities affecting the upstream Microsoft projects, follow their
[PowerShell](https://github.com/PowerShell/PowerShell/blob/master/.github/SECURITY.md) or
[Azure PowerShell](https://github.com/Azure/azure-powershell/blob/main/SECURITY.md) security policy.
